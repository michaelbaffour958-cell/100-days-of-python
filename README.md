## Day 002: Tip Calculator

A program that splits a restaurant bill, including tip, between a number of people.

**How to run:**
    python main.py

**Example:**
    Welcome to the tip calculator!
    What was the total bill? $100
    How much tip would you like to give? 10, 12, or 15? 12
    How many people to split the bill? 5
    Each person should pay: $22.40

**What I learned:**
- `input()` always returns a string, so convert with `int()` or `float()`
- f-strings insert values into text
- `round()` and `:.2f` control decimal places
